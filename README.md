# Liger's Furniture Palace® website

Static, mobile-friendly furniture catalogue for GitHub Pages.

## Before publishing
1. Edit `index.html` and replace `const WHATSAPP_NUMBER = '';` with your business number in international format, e.g. `const WHATSAPP_NUMBER = '27721234567';`.
2. Upload your two original furniture images as `images/product-1.jpg` and `images/product-2.jpg`. They are **not included** in this package because the original images are not available here.
3. Confirm product names, descriptions, prices, business details, delivery terms, and any required privacy/returns policies.
4. Preview and test the WhatsApp buttons before sharing your website.

## Publish on GitHub Pages
Create a public GitHub repository named `ligers-furniture-palace`. Upload `index.html` to the repository root and the `images` folder. Go to Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Your URL will be `https://YOUR-USERNAME.github.io/ligers-furniture-palace/`.
